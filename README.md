Noerz Activator

AM Activators Engine

Noerz Activator adalah web-based activation engine yang dirancang untuk membantu proses aktivasi dan verifikasi Alight Motion melalui sistem yang terintegrasi dengan API.

Features

- Send activation request
- Email verification
- Send & Verify workflow
- API integration
- Response normalization
- Error handling
- Responsive interface
- Modern and lightweight UI

Activation Flow

Enter Email
     ↓
    Send
     ↓
Check Email
     ↓
   Verify
     ↓
 Activation

How to Use

1. Enter Email

Masukkan alamat email yang ingin digunakan pada kolom yang tersedia.

2. Send

Tekan tombol Send untuk mengirimkan activation request.

3. Check Email

Setelah request berhasil, periksa inbox atau folder spam pada email yang digunakan.

4. Verify

Ikuti proses verifikasi yang tersedia untuk menyelesaikan proses activation.

API Integration

Noerz Activator menggunakan API untuk menangani proses Send dan Verify.

Sistem melakukan normalisasi response agar status dari API dapat ditampilkan secara konsisten pada interface.

Response Handling

Contoh status yang dapat ditampilkan:

SUCCESS
REQUEST FAILED
INVALID EMAIL
EMAIL NOT SUPPORTED
VERIFICATION FAILED
SERVER ERROR
